# River item artwork

These four 32px pixel sprites are original artwork authored for Cravera in `tools/forest_fishing_icons.py`: Reedwood Fishing Rod, Reed Perch, Jade Shardfin, and Moonscale. The integer-coordinate silhouettes, crystal fins, reed bindings, and reel were drawn specifically for this feature. No downloaded fish or fishing-rod artwork is used.

The source generator preserves transparent backgrounds. Godot imports with the project's nearest filtering, and ItemDB trims only excess transparent canvas. Fishing holes, cast arcs, rod/line/bobber, and the fishing interface are original Godot drawing code. Existing project fonts and CrystalFrame retain their existing licenses/provenance.
